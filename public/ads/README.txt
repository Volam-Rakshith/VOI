Put your .mp4 sponsor clips in this folder and list them in playlist.json, e.g.

  ["sponsor-one.mp4", "sponsor-two.mp4"]

One file is picked at random each time the break opens (15-second watch, skip arms after that).
An empty list is fine: the plate shows its own animated "AD SPACE" notice
and still runs the clock, so custom codes work even before any video exists.
